# 超人系统 × 后门（Superhuman Systems × Backdoors）

研究对象：**超人系统里的后门**。围棋（KataGo）与国际象棋（Lc0）作为试验田——
其地位类比交通标志之于 BadNets：试验田本身不是课题，它让"把后门植入一个
能力超过所有人类的系统"这件事变得可测、可复现。痛点定位为**可扩展监督**
（scalable oversight）：当被审系统强过一切人类验证者时，哪些审计手段还能
发现被植入的缺陷。

本仓库专用于该方向的研究记录。

## 为什么是围棋/国际象棋

- **真超人且可验证**：强度可用对局直接测，不需要人类偏好代理（对比 Arena Elo）。
- **公开的强度阶梯**：KataGo 有上千个公开历史网络，Elo 跨度数千，可当连续的
  "验证者强度"或"被审系统强度"轴。LLM 上没有同类资源。
- **真值可得**：局部官子/残局有精确解（解器、Syzygy 库），后门是我们植入的，
  审计是否命中可精确判分。
- **配置旋钮**：贴目、劫规则、计分规则（数子/数目 = KataGo 全局输入 [9]）、
  棋盘尺寸都可精确控制。
- **推理期搜索**：带 MCTS，可研究"搜索放大还是冲淡后门"。

## 已知的硬约束（坏消息先说）

1. LLM 上的证据（Control Tax、Engels Fig.13 等）指向：可检性由审计方决定，
   可能与被审方是否超人**无关**。若棋类复现，"超人"一半不承重。【类比档】
2. 棋类有同级独立引擎（Stockfish/KataGo/解器）可裁决异常着法，"后门藏在超人
   怪招后面"不是天然成立，需限定"验证者无同级引擎、不可加算力"。【推导档】
3. 稀有度是混淆变量，需弱臂对照（同一后门植入人类水平智能体）。【推导档】
4. 低维配置触发（如贴目）可被数据搜索/穷举扫描秒破，只能当阳性对照，不能
   当主触发器。【推导档】
