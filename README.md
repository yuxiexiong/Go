# 越过审计者之后：超人系统里的后门（Beyond the Auditor）

研究对象：**超人系统里植入的后门**。围棋（KataGo）是试验田，国际象棋（Lc0）备用。
试验田的地位类比交通标志之于 BadNets：它本身不是课题，它让"把后门植入一个能力超过所有人类的系统，再看人还能不能审出来"这件事变得可测、可复现。

> **主线句（固定；任何修改先对照它，不动它才改）：** 超人系统一旦强过所有审计者，"找更强的审计者来复核"这条兜底就不存在了。我们第一次在真超人系统上量出这个缺口有多大，并找出哪些现实可得的弱资源能把它补回来、补多少，给出"超人时代的审计该怎么做"的第一份有真值的答案。

**主问题：** 当一个系统强过所有人类审计者时，植入它的后门会不会变得审不出来？如果会，拿什么代替"更强的审计者"？问法（v1.3）：越过人类之后，审计成败由哪些因素决定、各占多少。"超人"承重在问题设定（AI 控制协议里那份"可靠的人工复核"不再成立），不依赖"超人掩护后门"成立。

**现行口径：`docs/PROPOSAL_v1_2026-11-27.zh-CN.md`（v1.7）。** 与其他文档冲突时以它为准；被取代的说法登记在它的 §12。

## 为什么是围棋

- **真超人且能力可验证**：强度用对局直接测，不需要人类偏好代理（对比 Arena Elo）。
- **公开的宿主阶梯**：KataGo 有 959 个公开历史网络（katagotraining.org，2026-11-26），从人类水平以下连续延伸到远超人类（推理全部可用；能微调植入的是 2023-03 以后有 PyTorch 检查点的网络）；同一网络还能用搜索量控制是否超人。LLM 上没有同类资源。
- **真值可得**：精确官子、Syzygy 残局库、解器；后门由我们植入，审计是否命中可精确判分。
- **人类锚点**：KataGo HumanSL 网络按段位模仿人类。
- **推理期搜索**：可研究搜索冲淡还是放大后门。

## 适用边界

结论适用于：能力可客观验证、行为不可审计、危害不经过语言的超人系统。对"连能力都验证不了"的通用超人系统只能算类比档。

## 已知的硬约束（坏消息先说；完整版见 PROPOSAL §1）

1. 棋类永远有客观输赢、没有语言通道，外推有上限。【推导档】
2. 棋类有同级引擎和解器可裁决异常着法，要外推的结论里审计者一律不给这些；"给同级引擎"只当上界臂。【推导档】注：Stockfish 14 起 NNUE 用 Leela 评估的局面训练（2021-06），"独立引擎"的独立性本身待测。
3. 参照检查点审计受漂移地板约束（MIST 2605.21146：离参照越远检出越差），第一道闸门就测它。【类比档】
4. 稀有度是混淆变量，需同一后门植入人类水平宿主作弱臂对照。【推导档】
5. 低维配置触发（如贴目）可被穷举扫出，只当阳性对照。【推导档】
