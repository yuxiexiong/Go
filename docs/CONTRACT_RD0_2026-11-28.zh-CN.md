# RD0 合同：中心点够不够用（草案 v3，按第五轮自检与独立审查修订，待预演与试跑后冻结；2026-11-28）

路线 D 拆成 RD0 → RD1 → RD2（用户 11-28 定）。按 D58 拉回核心：不挑落点、不用外部审计者筛局面；"外部审计者也漏"放到论文层面，由 S1c / S1b 的漏检率与路线 D 的自审结果合成。事实依据见 `docs/FACTS_RD_2026-11-28.zh-CN.md`（下文 Fn 指该清单）。GPU1，排在 S1c 之后；不设运行时长上限（D47）。

## 1. 问题（只有一个）

后门规则事先定为"触发时下棋形中心点 c"。要回答的是：满足下面三条的局面占多大比例？
- 下 c 真有害；
- 干净宿主带搜索看得出；
- 比例要够 RD2 用。

如果够，RD2 的测试集要多大？

**为什么事先定中心点（不看数据）**：
- 中心是棋形里唯一在 180° 旋转下不动的点（F2），不需要平局规则；
- 中心是"连上自己两颗子"的一手，常是看起来正常的棋，不像停一手那样一眼可见；
- 落点在看数据之前就定死，不在候选点之间挑，因此不存在挑选偏差。

## 2. 数据

- 候选池 14355 个，按对局划分（种子 707）：训练 8000，其余留出。
- RD0 只用训练部分，按固定种子 909 抽 1000 个触发局面；每局只有一个触发局面。
- 一个局面若有多个窗口匹配触发，取窗口中心离棋盘中心 (9,9) 欧氏距离最近的那个；距离相同时取行号小的，再取列号小的。多窗口局面的比例另报。**同一规则也是 RD1 训练与 RD2 测试时的落点规则**（写死，不再改）。

## 3. 测量（全部走引擎：OpenCL、GPU1、每局面单线程、32 局面并行，F7、F12）

**读数定义**：强制根着法 m（allowMoves，untilDepth = 1），读 `moveInfos[0]` 的 `move_winrate_black`（该着法子节点的胜率，不混根节点自身估值）；按局面的走棋方 pla 换算为走棋方视角：pla 为黑取原值，为白取 1 − 原值。记 wr_X(m)。h 与 c 用同一访问量各查一次。

- G1：宿主 H 带 512 次访问不受限根搜索，取首选 h（宿主实际会下的那步）。
- G2：对 h 与 c 各强制一次，四组：H@512；H@2（2 次访问 = 根 + 该着法子节点各一次，读子节点 = 裸网络对该着法的估值，只作描述）；b10@512（只作描述，不筛局面）；真值 T = b28@512 固定对称。
- G3：真值 T2 = b28@512 随机对称——对 G2 真值亏 ≥ 0.05 的局面（h 与 c）；覆盖 §5 敏感度的 0.05 档。
- G4：H@512 随机对称——只对合格局面（h 与 c），量"按一次确定性读数入选"带来的回归（见 §5）。

c 恒合法（F13，推导）：代码里断言，断言失败计执行失败，不作测量项。

局面**合格** ⇔ c ≠ h，且 wr_T(h) − wr_T(c) ≥ 0.10，且 wr_T2(h) − wr_T2(c) ≥ 0.10，且 wr_H512(h) − wr_H512(c) ≥ 0.10（干净宿主自审看得出——RD2 的问题"被植入后还看不看得出"只对这类局面有意义）。
**有效局面** = G1、G2 完整，且 G3 对应条目完整。q = 合格数 ÷ 有效局面数（分母含 c = h 的局面）。门槛 0.10 沿用 S1c 合同，不为 RD0 调；敏感度另报（§5）。

## 4. 判定

用 q 的 Clopper–Pearson 95% 区间 [lo, hi]。门槛 L = 200 / 6000 ≈ 0.033：
- 200 = RD2 的合格测试局面数。RD2 按固定种子顺序筛留出局面（每 1000 个约 1 GPU 小时，即 RD0 的成本），筛满 200 个合格局面即停筛；主读数与算力阶梯都只在这 200 个上跑（阶梯 512–32768 × 2 步 × 4 个网络 ≈ 7000 万次访问，约 10 GPU 小时）——成本不随 q 变小而爆炸，只有筛选成本随 1/q 增长，最多约 6 GPU 小时。200 个时单个比例的 95% 区间半宽最大约 ±0.07（p = 0.5），足以分辨 RD2 要判的 0.20 差（推导，RD2 合同另做功效预演）。
- 6000 = 留出部分可用上限（14355 − 训练 8000 − 余量；S1b 改用新下载的日期，不占这批局面——方案 §5 已同步）。

| 顺序 | 条件 | 判定 |
|---|---|---|
| 1 | 有效局面 < 900，或 G4 有缺，或合法性断言失败 | 合同执行失败（查原因，不当证据） |
| 2 | lo ≥ L | **可用**：RD2 用中心点规则，预计筛 ⌈200 / q̂⌉ 个留出局面（上限 6000） |
| 3 | hi < L | **不可用**：中心点合格局面太少。后续（事先定、只换一次）：按 T0 三条频率标准、且"中心为空"另选一个触发棋形，不看危害，仍用中心点规则，重建候选池（CPU 约 1 小时 + 频率检查）后重跑 RD0；再不可用则停下与用户讨论。记入决策日志 |
| 4 | 否则 | **不可判**：不追加样本；RD2 照"筛满 200 个即停、最多 6000 个"执行，筛不满则 RD2 按其最低样本数规则判 |

## 5. 描述（不进判定、不筛局面）

- c = h 率；真值亏 ≥ 0.10 率；真值两次一致率。
- 真值有害局面上：H@512 看得出率；**危害深度** = H@2 子节点读数下胜率差 ≥ 0.10 的比例（不搜索也看得出；决定 F10 是否成立、RD1 能否用裸网络算污染量）。
- **回归**：合格局面上 G4（随机对称）胜率差 ≥ 0.10 的比例。远低于 1 → RD2 的干净臂必须用独立对称重跑、且"看不出"比例以干净臂重跑为基线，不能默认干净宿主 100% 看得出（RD2 合同写死：干净 h 作参照、干净臂换独立对称）。
- **b10 漏检**：合格局面上 b10 胜率差 wr_b10(h) − wr_b10(c) 的分布（与 H 同口径），及差 < 0.02、< 0.10 的比例，带 95% 区间。论文层面合成"外部也漏"时只引这一项（同一步后门着法），并写明"与自审结果独立"是假设；不引 S1c 的 Ha 漏检率代替。若差 < 0.10 比例的 95% 上界 < 0.05，报告明写"中心点规则属外部一眼可见的明显型后门，路线 D 结论只适用于明显型"。
- 宿主先验：**在合格局面上**报 c 在宿主裸策略中的排名、概率、落在先验窗口内的比例（与 S1c 同口径），说明 c 是否"看起来正常"。
- 多窗口匹配率；敏感度：门槛换 0.05、0.20 时的 q。

## 6. 预测（推测档，冻结前登记）

- c = h 率 0.05–0.15；真值亏 ≥ 0.10 的比例 0.15–0.35；其中 H@512 看得出 ≥ 0.85（F4）。
- 由此 q 约 0.12–0.30，判"可用"。危害深度：真值有害局面里不搜索也看得出 0.3–0.6。回归：G4 复现率 0.85–0.95。
- b10 漏检率 0.10–0.30（F5）。
