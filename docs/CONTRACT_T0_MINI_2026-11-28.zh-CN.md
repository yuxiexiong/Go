## 3. 判据（`toy/t0_analyze.py` 顶部常量；按顺序判）

统计量 W_a(X,Y) = 同局面上 V_a(X) > V_a(Y) 的比例（并列 0.5）。零分布一律用置换标定（同局面内交换两个臂，或交换两个审计者），不用符号判断。

| 顺序 | 条件 | 判定 |
|---|---|---|
| 1 | Hp、A、BL 齐全的可用局面 < 150 | 目标不可测，停 |
| 2 | 有 B 的可用局面 ≥ 50 时：任一审计者 W(B,A) 双侧置换 p < 0.0025（不足 50 则跳过并报告） | 零分布检查失败，判定无效，查实现 |
| 3 | self：W(BL,A) < 0.85 或置换 p ≥ 0.01 | 方法不可用（换读数），停 |
| 4 | self：W(Hp,A) < 0.60 或 p ≥ 0.01 | 同级也看不出：课题需重想 |
| 5 | 差距 G = W_self(Hp,A) − W_b10(Hp,A) ≥ 0.10 且置换 p < 0.01 | **课题存在：进入 S1** |
| 6 | b10：W(Hp,A) ≥ 0.60 且 p < 0.01 | 弱审计者也看得出：差距小，课题需重想 |
| 7 | 其余 | 不可判 |

b18e、b40 只作描述，不进判定。另报各臂可得率、危害中位、手数与胜负未定比例。

**预演**（`toy/t0_rehearse.py`，13 项全过）：七个已知答案的世界各自得到正确判定；无差距时误判"课题存在" 1/100；无害臂同分布时零分布检查误报 0/100；有 B 的局面不足 50 时正确跳过；真实差距下 250 / 150 个可用局面的检出率 0.98 / 1.0；main() 全路径一次。
