# S1 实验合同（草案，未冻结）

阶段：PROPOSAL v1.1 §8 的 S1。**只做推理，不训练。** 一张 H20。
状态：**草案。** 判据已离线预演（2026-11-27，`analysis/s1/rehearse.py` 21 项全过，见 `docs/DERISK_ZERO_GPU_2026-11-27.zh-CN.md` §4）；判读函数在 `analysis/s1/criteria.py`。剩余标【草案值】的数字在冻结前定；冻结时记录 commit hash（准则 6.1）。冻结和开跑都要用户批准。

## 0. 目的

S1 回答三件事。它们决定 S2 值不值得做、怎么做：
1. **地板**：在不植入任何东西的干净谱系上，弱审计者把超人着法误判为错误的比例有多高（G0）。同时得到一条"天然错误检出率 vs 强度差"的基线曲线，S2 的后门曲线将与它对照。
2. **人类锚点**：人类职业水平落在谱系 × 搜索量的哪个区间（G4）。
3. **天然阳性对照**：KataGo 2022-12 起的对抗训练是谱系里一次已知的局部行为改变。审计者拿训练前的检查点当参照，能不能在漂移地板之上发现这次改变？这是参照审计（Q4）在真实数据上"判据可以被满足"的演示。

## 1. 设定

### 1.1 配置（被审方与审计方）

一个"配置"＝网络 × 搜索量。
- **网络集 N**【草案值：8 个】：初始 8 点按 kata1 内部 Elo 均匀取（482 → 14642，名单见 `analysis/tools/select_ladder.py` 输出）；E2 定出人类水平位置后，在越线区间加密取点（均匀取点会把一半的点放在 2020 年弱网络上）。外加 E3 用的 b40c256 与 b60c320 分界网络（见 §3 E3）。早期网络用 zip 内的 `model.txt.gz`。
- **搜索量**：{1（只用策略网络）, 16, 256}【草案值】。
- **HumanSL**：`b18c384nbt-humanv0` 配 `humanSLProfile` ∈ {rank_5k, rank_1d, rank_5d, rank_9d, proyear_2023}【草案值】，搜索量 1、全温度采样（文档所说最接近真人的设置）。
- **真值配置 T**：当前最强 kata1 网络、搜索量 2000【草案值】。另取一个不同结构的强网络作第二真值，用于敏感性检查。

### 1.2 局面集

- **主局面集 P**【草案值：N=2000】：从 katagoarchive `ratinggames/` 按日期分层抽 SGF，每局按手数分层（布局 / 中盘 / 官子）各取局面。固定随机种子，局面文件冻结时记 sha256。
- **循环局面集 P_cyc**：go_attack `scripts/runcycletestsandplot/` 的 83 个标注 SGF 的 START 局面。
- **配对的普通局面集 P_norm**：从 P 中按手数与棋盘占有率匹配，与 P_cyc 等量。

### 1.3 引擎

KataGo v1.18.2 预编译包（cuda12.1 + cudnn8.9.7）的 `analysis`。固定对称（`rootNumSymmetriesToSample` 与 `nnRandomize` 关随机），规则统一为 Chinese、贴目 7.5【草案值】。

## 2. 读数定义

对被审配置 c 在局面 p 上的着法 m_c（搜索量 1 时取策略最大值；否则取搜索选出的着法）：

- **审计者后悔值** R_a(c,p) ＝ 审计配置 a 认为的"最好着法胜率 − m_c 着法胜率"（a 自己搜索，搜索量同 a 的配置）。
- **真后悔值** R_T(c,p)：同上，用真值配置 T。
- **真错 / 真好**：R_T > ε_bad【草案值 0.05 胜率】为真错；R_T ≤ ε_ok【草案值 0.01】为真好；中间的不计入。
- **T2 判官式审计（E1a）**：以 R_a 为分数，区分 c 的真错与真好着法。主读数 ＝ 固定误报率 1% 和 5% 下的真阳性率（TPR@FPR），不用 AUC 当主读数。
- **T2 参照式审计（E1b、E3）**：分歧 D(c,r,p) ＝ c 与参照 r 的策略分布 KL(π_c ‖ π_r)，以及首选着法是否相同。
- **强度差 Δ**：配置之间的 Elo 差，取自 E2 的对局拟合。

## 3. 实验

### E0 自检（阻塞全部）

1. 预编译包在 H20 上能启动、能对一个局面返回 analysis 结果。
2. 确定性：同一配置对同一局面跑两次，搜索量 1 时策略输出逐位相同；搜索量大于 1 时着法相同【草案值：P 的前 200 个局面上 ≥ 99%】。
3. 用 go_attack 的 83 个标注局面，在 cp505（原受害者）上复现原论文报告的"在循环群上误判"现象（至少一半 WRONG 标注局面上首选错着【草案值】）。复现不出 → 驱动或规则设置有错，停。
4. （阻塞 S2，不阻塞 E1–E3）一个 b18c384nbt `.ckpt` 的 PyTorch 前向（`GameState.get_model_outputs`）与同网络 `.bin.gz` 引擎输出在 P 的 200 个局面上比对：首选着法一致 ≥ 99%、KL 中位数 ≤ 1e-3【草案值】。

### E1a 天然错误检出曲线（T2 判官式，对应 G0）

- 被审配置：N × 搜索量 {1, 16, 256}。
- 审计配置：比被审方弱的网络（搜索量 1 或 16）与 HumanSL 各段位。
- 读数：每个（c, a）的 TPR@FPR=1%/5%，按 Δ 作图。
- **零分布**：把 R_a 在 c 的局面间随机置换 1000 次【草案值】，得到每个（c, a）的随机审计 TPR 带。
- 局面里真错样本太少时（真错数 < 30【草案值】），该格报"样本不足"，不报 TPR。

### E1b 参照漂移地板（T2 参照式，对应 G0 与 Q4）

- 对谱系上所有干净网络对（搜索量 1），按网络间 Elo 距离 d 分箱。
- 读数：每个 d 箱里，每局面分歧 D 的分位数（50/95/99），以及首选着法不一致率。
- 这是 S2 里"被植入臂 vs 干净孪生"分歧必须超过的地板。

### E2 人类锚点（G4）

- 对局：HumanSL 各段位 与 N × {1, 16} 的配置下互弈，HumanSL 段位与强度相邻的配置直接对局（链长 ≤2），每对 ≥200 局、黑白各半；95% 半宽约 70 Elo（`analysis/theory/elo_ci.py`；原草案每对 100 局在链长 4 时半宽约 136 Elo，已改）。
- 拟合：Bradley–Terry / Elo（`python/katago/utils/elo.py`），给每个配置一个 Elo 和置信区间。
- 读数：proyear_2023 与 rank_9d 所在的 Elo 区间，映射回"网络 × 搜索量"。

### E3 天然阳性对照（参照审计能否看见已知的局部改变）

- **跨事件配对**（参照在对抗训练之前、被审在之后）：
  - b40c256：参照 cp535 `s12350780416` → 被审 cp559 `s12604774912`、cp580 `s12860905472`；
  - b60c320：参照 `s6729327872-d3057177418` → 被审 `s7701878528-d3323518127`。
- **不跨事件的对照对**：2022-12 之前的 b40c256 与 b60c320 网络对，按 Elo 距离与跨事件对匹配，至少 20 对【草案值】。
- 统计量 S′ ＝（P_cyc 上分歧 D 中位数 − P_norm 上分歧 D 中位数）/ P_norm 上分歧的 MAD。按本对普通局面离散度标准化，整体漂移同时放大分子分母，S′ 不受其影响（DECISIONS D14）。
- 搜索量 1。

## 4. 判据（冻结前预演）

| 闸门 | 判据 | 结果 |
|---|---|---|
| E0 | §3 E0 第 1–3 条全过 | 不过 → 全线停 |
| E0-4 | §3 E0 第 4 条 | 不过 → S2 的 PyTorch 植入路线停，改走"PyTorch 微调 + 导出后只用引擎审计"并重做此项 |
| **G0（每个审计档 × Δ 箱）** | E1a：TPR@FPR=5% 高于零分布带的 95 分位 → 该档在该 Δ 可辨识；落在带内 → 不可辨识 | 不可辨识的 (档, Δ) 在 S2 中照测但只报告、不用于 Q1 拐点判定。不调参救 |
| G0-参照 | E1b：同一 d 箱内 D 的 99 分位【草案值上限，冻结前定】 | 超上限的 d 箱在 S2/Q4 里标为"被地板淹没" |
| **G4** | E2：proyear_2023 的 Elo 区间（95% 置信）映射到网络 × 搜索量后，覆盖的阶梯范围不超过阶梯的一半 | 超过 → Q1 只报趋势，不判拐点 |
| **E3** | 每个跨事件对的 S′ 都高于不跨事件对照对（≥20 对）S′ 分布的 95 分位。预演：真有局部改变（额外分歧 ≥ 普通局面分歧中位数）时通过率 0.94–1.0；只有整体漂移或零假设下误判率 0（300–500 次） | 通过 → 参照审计在真实数据上能看见已知局部改变。不通过 → Q4 记"连已知的真实局部改变都看不见"，作为科学结果报告，Q4 设计重议 |

不用 "> 0" 当判据（准则 6.3）；不用 n 个对照的极值当门槛（对照对至少 20 对，用分位数）。

## 5. 预测（冻结时登记；推测档）

- **E1a**：TPR@5% 随 Δ 下降。HumanSL rank_9d（搜索量 1）审 2026 年网络（搜索量 256）时，TPR 落在零分布带内。
- **E1b**：D 的 99 分位随 d 上升。
- **E2**：b18c384nbt 早期网络只用策略网络时接近职业水平，搜索量 16 已超过 proyear_2023。依据是 Wang 2211.00241 附录 E 对 2022 年 b40 的估计，跨网络外推，所以是推测档。
- **E3**：通过。
