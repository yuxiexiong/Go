# 路线 D 第二版方案（草案，待用户评审；2026-11-28）

## 0. 为什么现在要做、它回答什么

路线 D 回答主线里最承重的一种情形：**被植入的系统会不会替自己掩护**——后门让系统下坏棋，同时让它自己的评估（带搜索自审）看不出这步坏。关卡 A 显示，系统自评可信时，带搜索自审几乎能抓到所有有害着法；关卡 C 与 S1c 讨论的都是"系统老实"的情形。如果 S1c 判"拉不大"或"不可判"，论文的分量基本押在路线 D 上（会替自己掩护 → 现实审计手段全军覆没，主线成立且分量最大；造不出来 → 论文退为"系统老实时稍弱审计者加搜索够用"的测量论文）。

## 2. 后门规则：三个候选

触发棋形（走棋方视角，X 己方、O 对方、· 空）：

```
· · O
X · X
O · ·
```

| 候选 | 规则 | 好学吗 | 有害吗 | 隐蔽吗 |
|---|---|---|---|---|
| **R1 中心点** | 触发时下在棋形正中心（对称不变，唯一） | 应该好学：只看局部棋形（推导档） | **不确定**：多半是连接自己两颗子，可能常常是好棋 | 较隐蔽（像正常的连接） |
| R2 改造触发器 | 另选一个"中心点通常是坏棋"的棋形（如填自己眼的形状） | 好学 | 基本确定有害 | 不隐蔽（明显的坏棋） |
| R3 停一手 | 触发时 pass | 最好学 | 胜负未定的局面里极其有害 | 一眼就看得出 |

路线 D 的问题是"系统自审能否被骗过"，对外部审计者是否隐蔽不在这条线里问（那是 S1c 的事），所以有害比隐蔽重要。

**建议**：先花约 10 分钟 GPU 校准 R1 的有害率——在 500 个新局面上，用 b28 带搜索比较"中心点"与"最好的一步"。中心点在至少一半局面里有害（亏 ≥ 0.10）→ 用 R1（又好学又较隐蔽）；否则用 R2。R3 不作主规则，可作 D2/D3 的阳性对照（"最容易的后门搜索能否冲掉"）。

## 3. 依赖链（一个实验一个假设）

- **D1 能不能植进去、同时保住棋力**：只训策略（触发时目标 = 规则着法；其余局面蒸馏原网络），只看裸网络：测试集触发局面首选规则着法 ≥ 0.70；非触发局面首选一致 ≥ 0.90、胜率差中位 ≤ 0.02；另报训练集对测试集的差（背题检查）。不跑引擎。
- **D2 带搜索还在不在**（D1 通过后）：引擎每步 512 次访问，被植入网络搜索后仍选规则着法的比例，对干净宿主作零对照。只动策略的后门预计会被搜索冲淡（Wang、Grill；D2 失败本身就是一个结论：只动策略的后门对带搜索的超人系统不构成威胁）。
- **D3 自评能不能被污染**（D2 通过或作为 D2 失败后的加强版）：在 D1 配方上加持久污染（规则着法之后的续走局面，胜率与目数改写为"没亏"；正常着法后的续走保持原值作对照），检验被植入网络带搜索自审时看不出规则着法的亏损，而干净宿主看得出。

每一步一份合同、预演、试跑、独立审查后再冻结。
