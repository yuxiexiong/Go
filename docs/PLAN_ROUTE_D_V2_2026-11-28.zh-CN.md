# 路线 D 第二版方案（草案 v2，按自查修订，待用户评审；2026-11-28）

## 0. 它回答什么、不回答什么（v2 更正）

路线 D 只回答一个问题：**最便宜的补救手段"让系统带搜索自己审自己"，在后门会替自己掩护时还靠不靠得住**（主张 M3，PROPOSAL §9.5）。关卡 A 显示系统自评可信时，自审几乎都能抓到；路线 D 看后门同时污染自评时这条补救是否失效。

**不回答**"现实审计者够不够用"：路线 D 污染的是被植入网络自己的评估，外部审计者（b18e、b40 等）用的是它们自己没被污染的网络——即使路线 D 完全成功，外部审计者照样看得出这步坏（关卡 C：对真正有害着法看出 94–95%）。"现实审计者够不够"由 S1b（缺口随强度差）与 S1c（攻击者能否针对性利用）回答。

草案 v1 写"论文分量基本押在路线 D 上、会掩护 → 现实审计手段全军覆没"——**这是错的**（D54 更正）。论文分量来自三处：外部弱审计者在多大强度差下开始漏（S1b）、能否被针对性利用（S1c）、自审这条补救在掩护下是否失效（路线 D），缺一不可。

## 2. 后门规则：三个候选

触发棋形（走棋方视角，X 己方、O 对方、· 空）：

```
· · O
X · X
O · ·
```

| 候选 | 规则 | 好学吗 | 有害吗 | 隐蔽吗 |
|---|---|---|---|---|
| **R1 中心点** | 触发时下在棋形正中心（对称不变，唯一） | 应该好学：只看局部棋形（推导档） | **不确定**：多半是连接自己两颗子，可能常常是好棋 | 较隐蔽（像正常的连接） |
| R2 改造触发器 | 另选一个"中心点通常是坏棋"的棋形（如填自己眼的形状） | 好学 | 基本确定有害 | 不隐蔽（明显的坏棋） |
| R3 停一手 | 触发时 pass | 最好学 | 胜负未定的局面里极其有害 | 一眼就看得出 |

路线 D 的问题是"系统自审能否被骗过"，对外部审计者是否隐蔽不在这条线里问（那是 S1c 的事），所以有害比隐蔽重要。

**若换 R2**：新棋形要按 T0 的三条标准重选（出现对局比例 0.15–0.60、每局中位 ≤ 3 次、中盘占比 ≥ 0.60），否则触发频率与局面分布会变，和前面各实验不可比。

**建议**：先花约 10 分钟 GPU 校准 R1 的有害率——在 500 个新局面上，用 b28 带搜索比较"中心点"与"最好的一步"。中心点在至少一半局面里有害（亏 ≥ 0.10）→ 用 R1（又好学又较隐蔽）；否则用 R2。R3 不作主规则，可作 D2/D3 的阳性对照（"最容易的后门搜索能否冲掉"）。

## 3. 依赖链（一个实验一个假设）

- **D1 能不能植进去、同时保住棋力**（植入成立以棋力不崩为前提，两条都过才算"能植入"）：只训策略（触发时目标 = 规则着法；其余局面蒸馏原网络），只看裸网络：测试集触发局面首选规则着法 ≥ 0.70；非触发局面首选一致 ≥ 0.90、胜率差中位 ≤ 0.02；另报训练集对测试集的差（背题检查）。不跑引擎。
  - **规则着法本来就是宿主首选的局面不计入植入率**（否则"植入"什么都没改变，植入率虚高）；校准时一并统计这类局面的占比。
  - **棋力保持的两档办法（事先写死）**：第一档 = 蒸馏局面 1 万以上、学习率 1e-5；第一档棋力判据不过 → 第二档 = 只微调最后几层（策略头与最后两个残差块）并加"离原始权重不远"的 L2 约束。两档都不过 → 判"植入必伤棋力"。
  - **加一小组对局直接量棋力**（D1 判据外，描述）：被植入网络对原网络，每步 128 次访问，100 盘；首选一致率只是代理指标。
- **D2 带搜索还在不在**（D1 通过后）：引擎每步 512 次访问，被植入网络搜索后仍选规则着法的比例，对干净宿主作零对照。**只在真值（b28 带搜索）认定规则着法有害（亏 ≥ 0.10）的测试局面上判**——搜索按价值选着法，无害的规则着法不会被冲掉，有害的才会，混在一起会把"存活"和"无害"混为一谈；无害局面的存活率只作描述。只动策略的后门预计会被搜索冲淡（Wang、Grill；D2 失败本身就是一个结论：只动策略的后门对带搜索的超人系统不构成威胁）。
- **D3 自评能不能被污染**（D2 通过或作为 D2 失败后的加强版）：在 D1 配方上加持久污染（规则着法之后的续走局面，胜率与目数改写为"没亏"；正常着法后的续走保持原值作对照），检验被植入网络带搜索自审时看不出规则着法的亏损，而干净宿主看得出。

每一步一份合同、预演、试跑、独立审查后再冻结。

**D3 的规模**（v2 补）：持久污染需要为每个触发局面建续走树（路线 D 冒烟：每局面约 2 × 8 手 × 2 棵 ≈ 34 个局面）；按 7000 个训练局面约 24 万个续走局面，数据准备与蒸馏教师输出比 D1 多一个数量级（GPU 约数小时，推测），合同里单列。

## 4. 数据

- 新增 2024-02-18 至 02-21 四天 kata1 自对弈棋谱（约 45 万…以实际解压数为准），CPU 多进程按同一标准（触发、宿主根胜率 [0.2, 0.8]、同局胜负未定的非触发局面）建候选局面池（`toy/prep_positions.py`），排除所有已用过的对局。
