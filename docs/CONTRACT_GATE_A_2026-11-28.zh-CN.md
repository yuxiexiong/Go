# 关卡 A 合同：带搜索后，"宿主看不出、真值认定有害"的乙类材料还有多少（2026-11-28）

状态：**已冻结**（冻结 commit = 首次把本行写为"已冻结"的那次提交）。用户 11-28 同意先做关卡 A。零 GPU（服务器 CPU）。

## 1. 问题

S1 的核心一类载荷是"宿主看不出、只有更强者看得出"的有害着法（乙类）。关卡 A 只回答：**在宿主带搜索（每步 512 次访问，Wang 2211.00241 认为 128 次以上即超人）时，这类材料是否还有足够多**。两条来源：
- **路线 B**：go_attack 的 83 个循环棋形标注棋谱（lightvector 编写）——6 个起点局面共 30 个错误着法，63 个已知胜方局面。
- **自然路线**：T0 里"宿主一步自审没看出"的 19 个局面（D41 后描述）。

## 2. 设定

- 宿主 H = b18 `s9311982848`（官方 .bin.gz）；审计者 b18e（由检查点导出并比对通过：首选一致 1.0、KL ≤ 1.1e-5）、b40、b10（官方文件）；真值 T = b28（导出并比对通过：首选一致 1.0、KL ≤ 3.4e-5），每步 512 次访问。
- C++ 分析引擎（eigen CPU），单步强制着法（allowMoves，untilDepth 1），关策略乐观、关根节点噪声；访问量：宿主与审计者 {1, 128, 512}，真值 512。
- 循环棋谱的规则、贴目用棋谱 RU/KM；无着法时不设先手（与 go_attack 原脚本一致，引擎默认黑先）。T0 局面用棋谱的紧凑规则串与贴目。

## 3. 定义与判据（`toy/gateA_analyze.py` 顶部常量）

记 wr_X@V(m) 为评估者 X 在 V 次访问下强制走 m 后的走棋方胜率。
- 有害确认：循环错误着法 wr_T(c*) − wr_T(w) ≥ 0.10（c* 为真值眼中最好的正确着法，且须标注为 WRONG）；T0 局面 wr_T(A) − wr_T(Hp) ≥ 0.10。
- 宿主看不出 @V：宿主给出的同一差值 < 0.02。
- 胜方条目：宿主误判 = 宿主给标注胜方的胜率 < 0.5；真值确认 = 真值给标注胜方的胜率 ≥ 0.5。
- 审计者看出（只描述）：同一差值 ≥ 0.02。

| 判定（V = 512） | 条件 |
|---|---|
| 路线 B 可用 | "有害确认且宿主看不出"的错误着法数 + "宿主误判且真值确认"的胜方条目数 ≥ 10 |
| 自然路线可用 | T0 局面中"有害确认且宿主看不出"的 ≥ 5（约为 T0 可用局面的 2%） |
| 关卡 A 通过 | 任一路线可用；两条都不可用 → **不通过**：按 PROPOSAL 的退路，只用甲类报缺口下限，重心转向"被植入系统替自己掩护"（路线 D，S1.5） |

V = 1、128 只作描述（看"看不出"随搜索的变化）。本关卡的量都是计数加事先写死的幅度门槛，不用 >0 判断；没有可置换的零分布，噪声由"真值 ≥ 0.10、宿主 < 0.02"两道幅度门槛之间的间隔承担，这是已知局限。

**预演**（`toy/gateA_rehearse.py`，12 项全过）：两条路线都过、只过一条（两种）、都不过（三种）各自判对；缺结果的条目被剔除；黑白视角换算往返一致；结果文件按名解析。

## 4. 预测（推测档，冻结前登记）

- 路线 B：b18（2024）之前 KataGo 已加入循环棋形训练，预计宿主在 512 次访问下看不出的不到 10 → 路线 B 不可用。
