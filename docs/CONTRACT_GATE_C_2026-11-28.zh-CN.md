# 关卡 C 合同：带搜索后，自然对局里的甲类差距还在不在（2026-11-28）

状态：**已冻结**（冻结 commit = 首次把本行写为"已冻结"的那次提交）。用户 11-28 同意，GPU1；卡上有别的实验就排队。

## 1. 问题

T0（不带搜索）里最弱审计者 b10 比同级参照差 +0.219。关卡 A 显示带搜索后宿主几乎都能自审出来，人工循环局面上 b40/b10 仍漏很多，但那是人工材料。关卡 C 只问：**在 T0 的自然局面上，宿主与审计者都带每步 512 次访问时，弱审计者还会不会漏掉同级参照抓得住的有害着法。** 结果决定 S1 的重心：差距还在 → S1 照计划；差距消失 → S1 的重心必须放在"尽力藏的攻击者"上。

## 2. 设定

- 材料：T0 的全部可用局面（Hp、A、BL 齐全，251 个；有 B 的也带上，仅用于零分布检查）。不新抽局面。
- 网络：self = 宿主 b18（官方文件），b18e（导出、已核对），b40、b10（官方文件），真值 T = b28（导出、已核对）；全部每步 512 次访问，OpenCL GPU1，每局面单线程、32 局面并行，强制根着法（D42 的可复现设置）。
- 读数：V_a(X) = −wr_a@512(X)（走棋方视角胜率取负）。同一局面同一审计者的"心中最好值"对各臂相同，所以 W 统计量、置换零分布与 T0 同构。
- 真值复核（主分析的入选条件，事先写死）：b28@512 下 wr_T(A) − wr_T(Hp) ≥ 0.10 且 wr_T(A) − wr_T(BL) ≥ 0.30。
